# Daily Muslim — Android test builds

A warm daily Islamic practice for families and friends: log the five prayers, then the **Daily Five** — morning azkar, a page of the Madinah Mushaf, a hadith, a mini-puzzle and evening azkar — together with your group.

## Download the latest version

**[⬇ DailyMuslim.apk (latest)](https://github.com/firas1886/daily-muslim/releases/latest/download/DailyMuslim.apk)**

All versions and their notes: [Releases](https://github.com/firas1886/daily-muslim/releases)

## Install on Android
1. Open the link above on your phone and download the APK.
2. Tap the downloaded file. If Android asks, allow installing apps from your browser or files app.
3. Open **Daily Muslim** and sign in with Google.

These are test builds while the app is in development; content such as hadith questions and azkar meanings is still being reviewed.
